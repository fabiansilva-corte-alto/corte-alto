Bandeja de clasificación
Selecciona la carpeta de un trabajador desde el explorador de tu computador — el sistema sugiere el tipo de cada documento, tú confirmas o corriges antes de subir.
Selecciona una o varias carpetas de trabajadores

El explorador de Windows solo permite elegir una carpeta por vez (Ctrl/Shift no funciona ahí). Para cargar VARIOS trabajadores de una sola vez, elige la carpeta que los contiene a todos (ej. "DOCUMENTACION LABORAL") y el sistema los separa automáticamente en una tarjeta por trabajador. También puedes elegir la carpeta de un solo trabajador (ej. "Aguilera Aguilera Reinaldo"), o volver a pulsar el botón para ir agregando más carpetas después.

Tipo de documentoOrigen

Los tipos predeterminados no se pueden eliminar (son los que usa el sistema para "Anexo — cambio de fundo" y el resto de las reglas), pero sí puedes cambiarles el nombre. Los tipos personalizados que agregues se pueden editar y eliminar libremente, salvo que ya tengan documentos subidos.

Nombre del fundoCentros asociadosVariantes conocidas

Este es el nombre que verá el jefe de faena al elegir el fundo en Cuadrilla diaria. Los centros asociados son solo una ayuda para marcar vigencia masiva — no reemplazan lo que informa cada jefe de faena en Cuadrilla diaria. "Detectar fundos similares" revisa los anexos de cambio de fundo ya subidos y te sugiere agrupar variantes de escritura (ej. "Los Alpes", "Los Alpes Hij", "Los Alpes Hijuela 1") bajo un solo nombre, y actualiza esos documentos para que queden escritos igual.
